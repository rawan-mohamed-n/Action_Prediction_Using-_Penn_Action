Kinematic Features
Preprocessing

Turning Raw Annotations into Clean Kinematics

Penn Action data has occluded joints, missing coordinates, and viewpoint variation. Four preprocessing stages handle each challenge.

🔍

Visibility-Aware Loading

Occluded joints are set to NaN rather than trusting corrupted coordinates. Honest missing data beats confident wrong data.

🪞

Mirror Symmetry

For front-facing poses, missing joints are estimated by reflecting visible contralateral joints across the head's vertical axis.

⚓

Anchor-Based Interpolation

Joints are converted to body-relative coordinates before interpolation — preventing "sliding" artifacts when the subject translates.

📐

Viewpoint Detection

Automatically classifies camera angle (Front/Back vs Side) using the shoulder-width to torso-height ratio. Determines which angle method to use.

Feature Extraction

8 Kinematic Angles × Summary Statistics

Eight joint angles computed per frame using viewpoint-aware methods, then compressed into fixed-length feature vectors.

📏

Baseline Frame

Reference frame where limbs are at natural length — max body height (standing) or max arm extension (hanging for pullups).

🔢

Dual Angle Methods

Side view: vector dot-product. Front view: arcsin ratio estimating 3D bend from 2D foreshortening.

📊

Sequence Summary

32 angle features (max/min/mean/var × 8 angles) + 26 movement features (std of each coordinate). Fixed-length per sequence.

⚖️

Normalization

Min-max scaling to [0,1]. Correlation removal (ρ > 0.90) and PCA (95% variance) reduce dimensionality before training.

Architecture

Modular Pipeline Design

Eight Python modules, each with a single responsibility. Run individually or orchestrate end-to-end via CLI.

pipeline/config.py

Central Configuration

All paths, joint definitions, feature schema, model paths, and per-action settings — single source of truth for batch and real-time.

pipeline/preprocessing.py

Raw Data → Clean DataFrames

.mat loading, visibility masking, mirror symmetry, single/dual anchor interpolation, viewpoint detection, baseline frame selection.

pipeline/feature_extraction.py

Clean Data → Feature CSVs

Batch processes all sequences: baselines, kinematic angles, joints/angles CSVs, summarizes and normalizes.

pipeline/training.py

Features → Trained Models

Loads summaries, one-hot encodes, removes correlated features, applies PCA, trains Random Forest and SVM.

pipeline/evaluation.py

Models → Reports & Plots

Classification reports, confusion matrices, feature importance, PCA variance, correlation heatmap.

pipeline/form_evaluator_training.py

Form Evaluator Models

Trains StandardScaler, RF action classifier (98.8% acc), and IsolationForest quality regressor (0.006 MSE). Exports .pkl artifacts.

pipeline/inference.py

Real-Time Webcam Inference

Threaded camera, MediaPipe Pose, sliding-window features, idle detection, and live HUD overlay with action + quality.

pipeline/classical_inference.py

Legacy Classical Approach

Architectural skeleton of the initial HOG+SVM + CSRT tracking design. Documented for narrative completeness of the architectural evolution.

Real-Time System

Live Webcam Inference Pipeline

From camera frame to action label + form quality score in real time, with intelligent gating to avoid wasted computation.

📹

Threaded Capture

Daemon thread reads frames into a single-slot queue. Main thread never blocks on I/O — always gets the latest frame.

🦴

MediaPipe Pose

33 body landmarks per frame with visibility scores. Low-visibility joints treated as NaN to prevent noisy predictions.

⏸️

Idle Detection

Y-axis variance of core landmarks over a 5-frame window. Below threshold → skip inference to save compute.

⚡

Async Inference

Background thread runs action + quality models every N frames on a 90-frame sliding window, decoupled from rendering.

Getting Started

Run the Pipeline

# Install dependencies
pip install -r requirements.txt

# Run the full pipeline (extract → train → evaluate → form-train)
python pipeline/run_pipeline.py --all

# Individual stages
python pipeline/run_pipeline.py --extract
python pipeline/run_pipeline.py --train
python pipeline/run_pipeline.py --evaluate
python pipeline/run_pipeline.py --form-train

# Launch real-time webcam inference
python pipeline/run_pipeline.py --infer
# Launch the legacy classical approach
python pipeline/run_pipeline.py --infer-classical
